## 發佈到 GitHub Pages

1. 把以上檔案上傳到儲存庫（可直接在網頁上拖曳，`assets` 資料夾要一併建立）。
2. 進入 **Settings → Pages**。
3. Source 選 **Deploy from a branch**，分支選 `main`，資料夾選 `/ (root)`。
4. 按 Save，等一到兩分鐘。
5. 網址會是 `https://<帳號>.github.io/<儲存庫名>/`

## 每次更新內容之後

**一定要做這一步**，否則使用者的手機會抓到舊的快取：

1. 打開 `sw.js`，把第一行的版本號往上加：
   ```js
   const VERSION = '3.4.0';   →   const VERSION = '3.4.1';
   ```
2. 同時把 `index.html` 裡的 `APP_VERSION` 改成同一個號碼，方便對帳。
3. 推上去。

若新增了檔案（例如 A02 課程），記得加進 `sw.js` 的 `PRECACHE` 清單。

## 手機端更新方式

一般情況下重開 App 就會拿到新版（導覽採網路優先）。若沒更新：

- **App 內**：我的 → 關於 → **強制更新**
- **iOS 頑固不更新時**：把 App 從主畫面刪掉 → 用 Safari 重新開啟網址 → 重新加到主畫面

換過圖示之後務必走一次 iOS 的完整流程，否則舊圖示會殘留。

## 三語切換

「我的 → 設定 → 語言」可切換 **繁體中文｜简体中文｜English**。

- 繁體是原文
- 簡體為即時轉換，內建 OpenCC 對照表，不需另外維護檔案
- 英文為對照字典，主程式 1,426 條、課程頁 921 條

切換時 App 會重新整理一次，**使用者記錄的資料完全不受影響**。
語言設定兩個檔案共用，從主程式進到課程頁會自動沿用。
